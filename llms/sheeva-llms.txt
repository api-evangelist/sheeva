# Sheeva.AI (SheevaConnect)

> Sheeva.AI (Parkofon Inc.) provides transaction infrastructure for connected vehicles — the SheevaConnect platform lets vehicles discover, authenticate, and pay for real-world services (fueling, EV charging, parking, tolling, QSR/curbside pickup, car wash) directly from the infotainment system, using patented location intelligence and tokenized in-vehicle payments. Generated by the API Evangelist enrichment pipeline; no provider-published llms.txt exists (404).

## APIs
- [SheevaConnect API Specification 2.0](https://api-spec.sheeva.ai/): Partner API for connected-vehicle payments and last-mile services (drivers, vehicles, sessions, service hubs, payments, wallet, webhooks, loyalty).
